# Voice AI Platform

## 概要

Voice AI Platform は、整骨院向けAIカルテ支援システムです。

## 目的

施術者のカルテ作成時間を短縮し、
音声入力とAIを活用してカルテ作成を支援します。

本システムは診断を目的としたものではなく、
施術者の記録作成を補助することを目的としています。
